leader = ,  (set in keys.lua, before plugins load)
Same key, different meaning: Ctrl-p opens the fzf file picker in normal mode, but in insert mode while the completion menu is open, nvim-cmp uses it to select the previous item. The LSP keys (gd, grr, K, …) only do something in buffers that have a language server attached. Most of them use the same keys as Neovim's defaults, so they work the same in a bare nvim.
